# 박자 반전! 백스테이지 (pygame 리듬 게임 버전)

공연 시작 30초 전, 무대 뒤 대기실. 음악가인 당신은 마지막 리듬 연습 중입니다.
그런데 15초가 지나자 매니저가 달려와 외칩니다.
**"긴급! 공연 콘셉트 변경! 이제 반대로 연주하세요!"**

| 과제 조건 | 게임 속 구현 |
|---|---|
| 장르: 미니 게임 | 30초 리듬 게임 |
| 주어: 음악가 | 기타를 치는 음악가 캐릭터 (키를 누르면 연주 동작) |
| 공간: 무대 뒤 | 분장실 거울, 앰프, 스피커, 장비 케이스, 커튼, 조명 트러스 |
| 돌발 상황: 규칙 하나가 바뀐다 | 15초에 매니저 등장 → 반대 방향키를 눌러야 정답 |

## 실행 방법

### 1. pygame 설치 (처음 한 번만)
VS Code에서 **터미널 → 새 터미널**을 연 다음 아래 명령어를 입력합니다.
```
python -m pip install pygame
```

### 2. 게임 실행
터미널에서 `main.py`가 있는 폴더로 이동한 뒤 실행합니다.
```
cd backstage-rhythm
python main.py
```
(GitHub에서 받으면 폴더 이름이 `backstage-rhythm`, zip 파일로 받으면 `backstage_rhythm`입니다.)
또는 VS Code에서 `main.py`를 열고 오른쪽 위 ▷ 버튼을 누릅니다.

> 소리 파일(`assets` 폴더)이 없으면 처음 실행할 때 자동으로 만들어집니다.

## 조작 방법

| 키 | 기능 |
|---|---|
| ← ↓ ↑ → | 노트 치기 |
| Enter / Space | 게임 시작 |
| M | 소리 켜기 / 끄기 |
| Esc / P | 일시정지 (일시정지 중 Esc: 처음 화면) |
| R | 결과 화면에서 다시 시작 |

다른 창을 클릭하면 게임이 자동으로 일시정지됩니다. Space 또는 클릭으로 계속할 수 있습니다.

## 게임 진행 (BPM 144, 총 30초)

| 시간 | 구간 | 내용 |
|---|---|---|
| 0~10초 | 리허설 | 2박마다 노트 하나, 드럼 + 멜로디 |
| 10~15초 | 긴장 고조 | 1박마다 노트, 베이스와 스네어 추가, 주황 조명 |
| 15초 | 돌발 상황 | 경보음, 매니저 등장, 규칙 반전 |
| 15~25초 | 반전 리듬 | **반대 방향키**가 정답, 보라색 조명, 처음 6초는 레인 아래에 누를 키 안내 |
| 25~30초 | 피버 타임 | 반 박 노트 추가, 무지개 조명, 반전 규칙 유지 |

- 반전된 노트는 **보라색 테두리**로 표시됩니다.
- 규칙이 바뀌는 순간 헷갈리지 않도록 15초 앞뒤로 노트가 없는 쉬는 구간이 있습니다.

## 점수

- PERFECT(±0.07초) +100점 / GOOD(±0.14초) +50점 / MISS 0점
- 10콤보마다 노트당 보너스 +5점 (최대 +25점)
- 정확도 = PERFECT 100%, GOOD 50%, MISS 0%로 계산한 평균
- 정확도에 따라 S / A / B / C 등급

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 게임 실행, 화면 그리기, 키 입력 |
| `game_logic.py` | 판정, 점수, 콤보, 정확도 계산 |
| `chart.py` | BPM, 구간 시간, 노트 패턴 (음악과 판정이 함께 쓰는 기준) |
| `sound_maker.py` | 8비트 음악과 효과음을 직접 만들어 WAV로 저장 |
| `test_game.py` | 자동 기능 테스트 (`python test_game.py`) |
| `assets/` | 만들어진 소리 파일 |

음악은 외부 음원 없이 `sound_maker.py`가 Python으로 직접 합성합니다.
노트 하나하나가 멜로디 음과 같은 타이밍이라, 노트를 맞히면 음악을 연주하는 느낌이 납니다.

## 박자가 어긋나게 느껴질 때

컴퓨터나 이어폰(특히 블루투스)에 따라 소리가 늦게 들릴 수 있습니다.
`main.py` 위쪽의 `AUDIO_LATENCY = 0.03` 값을 조절하세요.
- 박자에 맞게 눌렀는데 **늦었다**고 판정되면 → 값을 **키우기** (예: 0.08)
- **빨랐다**고 판정되면 → 값을 **줄이기** (예: 0.0)
